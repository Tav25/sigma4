# SIGMA4 0.1.28 — S22. Редактирование длины стены

**Базовый SHA:** `d664fddd0fcbdd1c8c3f8acc53d7820a1bba636b` (v0.1.27). Ветка: `sigma4`.

- В 2D-инспекторе длина задаётся в метрах до 1 мм, с выбором неподвижного конца.
- `PLAN_SET_INTERIOR_LENGTH` изменяет только авторские координаты; общий ID узла не меняется. Недопустимые геометрические соединения отклоняются целиком, без записи в JSON и историю.
- `preservePlanOpeningAttachments` запрещает изменения, пересекающие существующие проёмы. Предпросмотр при перетаскивании узла/стены теперь использует ту же проверку привязок, что и команда.
- Unit тесты: направление и неподвижный конец, одно Undo, JSON roundtrip, Т-узлы, дверь, legacy. Chromium проверяет интерфейс, одну операцию Undo/Redo и сохранение Т-стыка.

**Ограничения:** только ортогональные стены; автоматическое создание новых Т/X-узлов при удлинении не делается. Геометрия не подтверждает несущую способность. Визуальная приёмка пользователем отдельна.

**Правила SIGMA4:** ветка `sigma4`, исходный SHA; JSON единственный источник истины; диагностика/тесты; без force/reset; один коммит после проверок и остановка до приёмки.
