# SIGMA4 — S06.4: гаражные ворота США/Канада

Версия ПО **0.0.18**. Ветка: sigma4. Исходный HEAD: 6b6055e6afb91bd96116853c69cf7eb42a07a84a.

## Основания проектирования (североамериканские источники)

- **США:** International Residential Code (2024), R602.7 (несущие перемычки) и R602.10.6.3 (PFG portal frame at garage). APA — Engineered Wood Association, Frequently Asked Questions About Portal Frames (TT-080).
  - https://codes.iccsafe.org/content/IRC2024P2/chapter-6-wall-construction
  - https://www.apawood.org/guides-tools-training/technical-document-library/technical-topics/frequently-asked-questions-about-portal-frames/
- **Канада:** BC Building Code 2024, 9.23.12 (Framing over Openings), указания City of Edmonton Detached Garage Design Guide, «Wall openings, including overhead door lintel». Ширина пролёта, нагрузки и выбор материала определяют сечение балки. При пролёте более 3 м руководство Эдмонтона требует минимум две опорные стойки под перемычкой плюс одну стойку до верхней обвязки с каждой стороны.
  - https://www2.gov.bc.ca/gov/content/industry/construction-industry/building-codes-standards/bc-codes/2024-bc-codes
  - https://www.gov.edmonton.ab.ca/sites/default/files/public-files/Detached_Garage_Design_Guide.pdf
- **Clopay residential overhead sectional door installation:** rough opening approximately door size (verify finished opening for selected model); minimum sideroom 3¾ in ≈ 96 mm, torsion spring headroom 12 in ≈ 305 mm, backroom height + 18 in ≈ 457 mm. More room may be needed for automatic opener. These are a **manufacturer-specific reference profile, not validated available site clearances**.
  - https://www.clopaydoor.com/residential/buyingguide/how-to-install-garage-door

## Реализация

- Отдельный `type:'garage-door'` на любой стене; логическое дерево содержит самостоятельную группу «Гаражные ворота». ID G01, G02 ... Изменение ширины, высоты, положения U; без порога.
- Пресеты размеров: 8×7 ft (2438×2134 мм), 9×7 ft (2743×2134 мм), 16×7 ft (4877×2134 мм), а также ручной ввод.
- `opening.garage` — канонические параметры типа и требуемые производителем монтажные зазоры, глубина **предварительного** изображения перемычки и число jack studs. Редактор и генератор вычисляют их из одного JSON.
- Стойки king/jack, разрезанная нижняя обвязка, длинная перемычка с ролью `garage-lintel-preview` (не утверждённый несущий элемент), верхние укороченные стойки. Визуально предварительная перемычка выделена цветом.
- Независимый валидатор запрещает отрицательные размеры, отсутствующую спецификацию, приподнятый гаражный порог, недопустимое число стоек, произвольный тип профиля. Для пролёта более 3000 мм в программе не разрешено меньше двух опорных стоек/сторону — **это не полный расчёт**.
- Независимые постоянные предупреждения: `GARAGE_LINTEL_REQUIRES_ENGINEERING`, `GARAGE_BRACING_AND_TRACK_CLEARANCES_UNVERIFIED`. `engineeringStatus` всегда `not_evaluated`.

## Строгие ограничения

**SIGMA4 НЕ рассчитывает**: нагрузки от кровли, перекрытий, снега, ветра и сейсмики, таблицы пролётов header/lintel, податливость балок, стойки по нагрузке, portal frame с креплением обшивки и анкеров к фундаменту, реальный доступный headroom/sideroom/backroom, противопожарные и энергоэффективные требования. Параметр lintelPreviewDepthMm — только временный визуальный габарит, не результат инженерного расчёта. Не использовать образцовую геометрию как рабочую строительную документацию.
