# SIGMA4 — S05.7: correction of California corner 90° rolled stud

Branch: `sigma4`, baseline: `d317d6163fc1b279499a3c8d6e2c52f964fccd67`. Version: `0.0.14`.

## Defect and fix

The 45×145-mm backing stud was rolled 90° but positioned as if its section were centred on the X reference. In the scene geometry its actual X span was 5882.5–6027.5 mm, intersecting the facade end stud and protruding 27.5 mm beyond the 6000-mm facade. The old validator used the same incorrect centred interpretation, so the saved JSON wrongly reported `valid: true`.

Generator correction: for a +90° rolled Y-axis member, its X reference is the *start* of the 145-mm face; `x = facade length - stud width - stud depth`. For facade 6000, timber 45×145: `x=5810`, projected X span `5810–5955`; adjacent end stud spans `5955–6000`. Horizontal section: backing Z `-72.5..-27.5`, side starter Z `-117.5..-72.5`. Contact only, without volumetric overlap.

Validator now uses the actual reference convention for rolled studs both in wall-bound checks and in opening-intersection checks. Import validates user-provided source parameters, regenerates the entire assembly and validates the regenerated snapshot, allowing the previously exported bad generated geometry to be repaired. Existing legacy import test retained.
