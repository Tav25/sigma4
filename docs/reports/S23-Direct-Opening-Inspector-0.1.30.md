# SIGMA4 0.1.30 · S23 — проёмы, подоконник и прямой 2D-инспектор

Base SHA: `46204600944c82e638dba22432dda9d9a48e68a9` (ветка sigma4).

Реализовано:
- Выбранные наружные окна, двери и ворота получают параметры предварительной перемычки (высота 90–610 мм, 1–4 опорных jack-стоек с каждой стороны) в общем инспекторе 2D, без поиска скрытых форм.
- Сохранение выполняется одной командой PLAN_FRAME_SAVE_OPENING; профиль хранится в каноническом JSON. Сборка и валидатор формируют actual header/king/jack geometry. Внутренние ненесущие двери не получают неподтверждённую несущую перемычку.
- Независимая проверка геометрии подоконной доски и существующих нижних коротких стоек у окон. Повреждения выявляются через verifyOpeningFraming и нарушают валидацию уже построенной модели.
- Добавлены regression unit cases для отсутствующей или смещённой подоконной доски, короткой опоры; Chromium проверяет новый инспектор и итоговый JSON/3D.

Границы:
- Наружные стены по текущему базовому профилю получают предварительное конструктивное обрамление. Тип несущей функции из ещё не выполненного 0.1.29 этим этапом не подменяется.
- Не выполняется расчёт несущей способности, конструктивных нагрузок, крепежа, разрешения по IRC/CSA.
- Сохранён принцип source JSON → derived assembly; без миграции старых тестовых проектов.

Регламент: SHA перед работой, ветка sigma4, без force/reset, этап принят по успешному CI и визуальной проверке.
