# SIGMA4 — S05.5: угловые стойки вплотную

Дата: 2026-11-02
Ветка: `sigma4`
Коммит реализации: `c1cd0c07ab9b2fb32ca72801a942f059336165d1`
Статус: READY_FOR_USER_TEST — не принято

## Ошибка
На скриншоте пользователя внутренняя дополнительная стойка стоит **на 55 мм левее наружной угловой стойки**. В сравнении с эталонной фотографией должна непосредственно к ней примыкать: вертикальные доски образуют компактную Г-образную группу у торца.

## Исправлено
- Перенесена `warm-corner-stud` к торцу фасада: вместо `x = length - sectionHeight + sectionWidth/2` используется `x = length - 2*sectionWidth + sectionWidth/2`.
- Для фасада длиной 6000 мм, сечение 45×145 мм: внутренняя стойка теперь X=**5910..5955 мм**, наружная — X=**5955..6000 мм**. Между гранями нет зазора и нет наложения объёмов.
- Боковая стойка проходит перпендикулярно у задней грани обеих фасадных стоек, в плоскости Z=-117.5..-72.5 мм.
- Между тремя соприкасающимися стойками зазора под утепление не заявляется: утепляется соседняя полость стены.
- Обновлены `connectionIds`: внутренняя стойка соединена с наружной и с первой стойкой боковой стены.
- Исправлены геометрические проверки и ожидания для импорта старого JSON; пересчёт сборки при импорте ставит стойку в новое положение.
- Сохраняются прочие размеры/проёмы/Undo/Redo.

## Проверено
Из GitHub повторно прочитаны все четыре изменённых файла и SHA ветки. Расчёт координат подтверждает `inside.max.x = outer.min.x = 5955` мм.

**Полный запуск `npm test`, `npm run build`, `npm run lint` в этой среде невозможен и не проводился.** Для приёмки пользователь запускает сборку и визуально осматривает модель.

## Приёмка
1. Обновить программу, добавить правую стену или импортировать предыдущий JSON.
2. Посмотреть угол сверху: левая добавленная стойка должна стоять **вплотную** к крайней фасадной стойке, а не отдельно.
3. Три стойки имеют сечение 45×145 мм, доски не проникают друг в друга.
4. Длина фасада меняется, угол остаётся цельным. Undo/Redo восстановление.
5. Запустить `npm test`, `npm run build`.
