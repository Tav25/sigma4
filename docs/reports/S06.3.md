Дата: 2026-11-02

База Git: f1cde21213ea26221c065323cc77f56d3cc1f1cc
Версия ПО: **0.0.17** — из package.json в UI и синхронизированном package-lock.json.

## Изменения

1. Окна/двери теперь можно создавать на любой выбранной стене. Поиск свободного участка учитывает только проёмы данной стены; окно фасада оставляет конструктивный зазор у калифорнийского угла. Дубликаты W/D идентификаторов исключены после импорта файлов и Undo; выбранный проём задаётся только после успешной команды.
2. Источник истины остаётся JSON: `building.openings[{id, wallId, type, positionUmm, widthMm, heightMm, sillHeightMm}]`, `building.markers` и `building.walls[*].openings`. В `ProjectStore` устранено сохранение UI-поля `positionXmm` внутри канонического Opening.
3. `projectToScene` отдаёт обратно совместимый `openings` для редактора и `sceneOpenings` для 3D, с независимыми origin, ориентацией стены, длиной и ID. Маркеры проектируются на наружную сторону обеих поддерживаемых осей.
4. `opening-geometry.ts` — общие чистые функции преобразования координат между локальными осями U/V и мировыми X/Y/Z.
5. `SceneView`: плоскости попадания курсора и контуры проёмов трансформируются каждым своим модулем стены; перетаскивание вычисляется по пересечению луча с плоскостью нужной стены, а не общей плоскостью Z=0; ограничения позиции применяются лишь к проёмам той же стены. Выбор кликом в 3D автоматически переключает панель на стену-владельца.
6. `multi-wall-openings.test.ts`: генерация досок окон и дверей второй и девятой стены, кватернион и Raycaster, маркеры, перенос при смене origin, отрицательные примеры пересечений, Undo/Redo, импорт/экспорт JSON и удаление.
7. Chromium: добавить окно и дверь на второй стене и дверь на девятой, экспортировать проект, проверить принадлежность и доски, сделать 3D-скриншоты.

## Границы этапа
- Прежние правила стыков S06.2 неизменны: первая пара — California corner, последующие — допустимые прямые стыки.
- Проёмы/рамы привязаны к локальной оси стены, а не к положению камеры.
- Двери остаются типом Opening; нет дверных полотен, фурнитуры, инженерного расчёта и T-образных узлов.
- Формат схемы JSON `1.0.0`, генератор/правила `1.0.0`; физическая сборка детерминирована.
- На стенах по-прежнему только направления +X и -Z, которые поддерживает S06.2.
