# SIGMA4 0.1.39 — непрерывные контуры соединённых стен

База: `307156478c864f3010306801972293067435eb78`, чистая ветка `sigma4`, версия 0.1.38.

Причина: отдельные наружные полосы и перегородки рисовались с собственными обводками. Торцевые линии пересекали общий материал в L/T/X-примыканиях.

Исправление: `plan-wall-outline.ts` вычисляет объединение ортогональных прямоугольных следов стен через сетку точных координат. Обводятся только границы занятых и пустых ячеек; внутренние границы не рисуются. Заливка остаётся общей штриховкой. Открытия вырезаются прежней маской, косяки рисуются прежними символами. Взаимодействие со стенами сохранено отдельными прозрачными областями; выделенная стена подсвечивается без возврата швов.

Затронуты только отображение плана, новый независимый алгоритм/тесты, номера версий. Авторский JSON, производный каркас, габариты и площади не изменяются. Это исправление оформления, не изменение узлов каркаса и не подтверждение инженерной прочности. Разные типы стен в будущем потребуют отдельной политики графического разделения.

Проверки:
- Сначала воспроизведена отсутствующая реализация новым тестом; затем 4 теста проверили T, L, X, свободный торец, пустой вход и примыкание в приложенном проекте. Проверки используют заданные площади и координаты границ, а не сравнение алгоритма с самим собой.
- `npm run lint`: успешно.
- `npm test`: 440/440, 56 файлов, 4 новых теста.
- `npm run build`: успешно; прежнее предупреждение Vite о размере bundle остаётся.
- `git diff --check`: успешно.
- Браузер: 0.1.39, образец 11×7 м, три помещения, 5 проёмов; проверены отсутствие швов на четырёх углах и Т-примыканиях, сохранность дверных косяков и линий проёмов. Снимок: `screenshots/plan-0.1.39.png`.
- 3D не изменялся. Полный браузерный smoke предусмотрен GitHub Actions, статус CI сообщается отдельно.

Файлы: `src/core/plan-wall-outline.ts`, `src/core/plan-wall-outline.test.ts`, `src/components/FloorPlanEditor.tsx`, `package.json`, `package-lock.json`, этот отчёт, снимок.
