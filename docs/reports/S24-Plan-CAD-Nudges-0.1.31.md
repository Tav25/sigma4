# SIGMA4 0.1.31 · S24 — точное редактирование плана

Base SHA: `ea116d603c4c48f1e95d564cf67560d1c1cfabdd`. Текущая ветка sigma4. Переиспользуются существующие ProjectStore-команды; нового источника геометрии нет.

Реализовано:
- Стрелки сдвигают выбранную перегородку строго перпендикулярно её оси, а окно/дверь/ворота — вдоль авторского направления своей стены. Учитывается реверс направления сегмента (U). Для выбранного графового узла стрелки перемещают сам узел через PLAN_GRAPH_MOVE_POINT.
- Шаги: обычная стрелка 25 мм, Shift 100 мм, Alt 1 мм; не перехватывать стрелки при вводе чисел и во время размещения проёма. Нельзя смещать объект произвольно по неверной оси.
- Контекстные кнопки ±25 мм для выбранной перегородки и проёма. Каждое подтверждённое перемещение — отдельная операция Undo/Redo; недопустимая геометрия отклоняется без изменения JSON.
- Сетка теперь переключается визуально. Её скрытие не меняет шаг привязки, координаты и сериализованный JSON.
- Unit: ориентация X/Z, реверс и допустимые шаги. Chromium: сетка, стена, стрелки, проём, кнопки и Undo.

Ограничения:
- Текущие привязки, орто-режим и размеры наружного прямоугольника остаются; полноценного универсального CAD-редактора произвольных многоугольников пока нет.
- Для проверки фактической геометрии/конструкции используется существующий независимый валидатор; инженерная несущая способность не утверждается.

Регламент: отдельный этап после 0.1.30, целевая ветка sigma4, без переписывания истории; фактический CI и визуальная приёмка.
