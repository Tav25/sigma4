# SIGMA4 v0.1.1 — редактор внутренних стен (этап S08)

Версия: **0.1.1**. Следующая версия по утверждённому пользователем порядку: **0.1.11**.
Ветка: `sigma4`. Точка старта: `b3d3acedb7b62cf06f8d3f9e5608c1193c35d1b5`.

## Функции этапа
- Новый режим черчения внутренних стен в редакторе `План 2D`: две привязки на существующих наружных / внутренних отрезках, мышью; координаты сохраняются в миллиметрах.
- Выбор стены, визуальное выделение, точное редактирование X/Z начала и конца, толщины (50–500 мм), удаление, Undo/Redo.
- Валидация до фиксации команды: обязательная привязка обоих концов, ортогональность, длина от 300 мм, отсутствие наложений и выхода за наружный контур, уникальные ID.
- Зависимые Т-соединения нельзя осиротить перемещением или удалением опорной стены. Крестообразные пересечения разрешены и изображаются вычисленными узлами; в JSON исходные сегменты не дублируются.
- `building.floorPlan.interiorWalls` остаётся каноническим источником истины, а прежний `building.walls` / 3D-каркас не меняется при черчении.
- Испытания: новые unit/store проверки и дополнительный браузерный Playwright сценарий для двух перегородок, выбора, изменения толщины, защите от удаления опорной стены и обратного экспорта JSON.

## Принятые геометрические решения
- Наружный периметр — замкнутый контур; внутренние стены на этом этапе — **осевые отрезки**. Физическая толщина хранится в JSON, но не выдавливается в 2D, чтобы не менять внешние размеры здания.
- Каждый конец новой перегородки обязан лежать на наружной либо другой внутренней стене. Зависимости валидируются на всех командах и импорте; перекрытия отрезков запрещаются.
- При пересечении двух осевых стен вычисляется единый визуальный узел, без скрытого изменения исходных сегментов. Конструктивная обработка крестового или Т-узла при генерации досок — отдельная задача.

## Что не входит
- Создание объёмного каркаса из плана, автоматическая разбивка комнат на помещения и вычисление их чистых площадей.
- Реальные физические соединения досок, инженерный расчёт несущей способности.
- Косые/криволинейные перегородки, свободно висящие концы, магниты к произвольной координате вне стены.

**Правила SIGMA4:** только ветка `sigma4`, без force/reset, JSON единственный источник истины, валидация до записи, проверка сборки, тестов и реального Chromium. Один осмысленный коммит, затем пользовательская приёмка. Следующий этап — только версия 0.1.11 после решения пользователя.
