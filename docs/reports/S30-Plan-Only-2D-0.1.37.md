# SIGMA4 0.1.37 — откат дублирующего 2D-сечения

База: `af7b2ba048f3a7c98d8de19e7999a4b97f94d141`, ветка `sigma4`.

## Решение
- В 2D оставлена только планировка; переключатель «Каркас 2D», управление сечением Y, SVG-слой физических сечений, инспектор физических деталей и их состояние полностью удалены.
- Связанный компонент `PlanStructuralOverlay.tsx` и тест только для его интеграции удалены. Данные о досках больше не передаются в 2D-редактор.
- Этап 2D-03 сохранён: быстрые инструменты слева, контекстные свойства справа, редактирование точек открытого контура, размеры и площади, отзывчивая компоновка.
- Горизонтальные сечения в 3D (`HorizontalSection`), а также общий точный геометрический алгоритм `buildHorizontalCut` и его независимые тесты не изменены.
- Браузерная проверка подтверждает отсутствие управления сечением в 2D как до, так и после сборки, наличие переключателя 3D-сечения, сохранение площадей и JSON.

## Инженерные ограничения
Визуализация 3D-сечения отражает геометрию деталей, но не подтверждает их прочность по IRC/NDS.
Никаких новых параметров авторского JSON или миграций нет.

**Регламент:** фиксировать SHA до изменений; одна проверяемая группа изменений; без force/reset; CI и браузерный smoke перед приёмкой.
