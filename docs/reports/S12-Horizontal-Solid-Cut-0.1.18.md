# SIGMA4 v0.1.18 — точное горизонтальное сечение всего каркаса

Ветка: \`sigma4\`. База перед изменениями: \`3cc387a96e310860fb02d8ad8e5e5f52275b9b22\`.
Изменения затрагивают только расчёт и представление разреза и версию приложения; структура канонического JSON сохраняется.

## Принцип
Горизонтальная плоскость \`Y = h\` (мм от основания) действительно пересекает каждый сгенерированный объёмный деревянный элемент из \`projectToScene\`. Сечение строится по мировым вершинам ориентированного 3D-параллелепипеда — с учётом начальной точки, поворота стены, \`reversed\`, собственного \`orientation\` и \`roll\`. Алгоритм находит пересечения 12 рёбер с плоскостью, дедуплицирует точки и строит выпуклый многоугольник; применяется полуоткрытый диапазон по высоте (нижняя граница включена, верхняя исключена), чтобы соседние пластины не дублировались на одной отметке. Это НЕ упрощённая проекция габаритного AABB.

## Интерфейс
- Кнопка «Горизонтальный разрез» доступна для любой непустой 3D-сборки, а не только для linked 2D-проектов с перегородками.
- Высота: точное числовое поле (шаг 1 мм), интерактивный ползунок, кнопки ±100 мм.
- Рисуются только реально пересечённые элементы, как SVG-многоугольники в плоскости X/−Z; пересечение из 3D сохраняет физические размеры в мм.
- Различие цветов: наружные элементы, специальные приёмные закладные, внутренние стойки и обвязки.
- Показ количества пересечённых деталей, выбор конкретного элемента с ID и ролью, масштабирование ± и «Вписать».
- Габариты вида фиксируются по всей 3D-сборке, чтобы проекция не прыгала при изменении высоты. Сохраняется возможность вернуться в 3D.

## Ограничения
Это архитектурная визуализация реальных пересечений деревянных прямоугольных брусков. Она не является расчётом несущей способности, проверкой крепежа или универсальным инструментом сечений произвольной скульптурной геометрии. Базовая ориентация сечения — горизонтальная плоскость; наклонная плоскость сечения не входит в версию.

## Регламент SIGMA4
Только ветка \`sigma4\`, проверка SHA до работы; JSON — источник истины, визуализация производная; изменения не перезаписывают историю; строгая типизация, тесты, сборка и браузерная регрессия. Следующий этап — только после пользовательской приёмки.
