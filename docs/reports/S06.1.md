# SIGMA4 — этап S06.1: модульная стена и дерево проекта

Дата: 2026-11-02
Ветка: `sigma4`
Исходный коммит: `a45fee15aa8546998201f28a0a85dd192482f144`
Версия ПО: **0.0.15** — единая в `package.json`, `package-lock.json` и верхней панели приложения.

## Состав изменения
- `src/core/wall-module.ts`: генерация **одной** стены из параметров и её собственных проёмов, фильтрация по `wallId`. Нет отдельных генераторов для «первой», «второй» стены.
- `src/core/corner-connection.ts`: правила калифорнийского угла вынесены из универсального модуля и применяются к производным доскам.
- `src/core/project-tree.ts`: дерево проецируется на существующие `building.walls`, `building.openings`, `assembly.elements` без копирования в JSON.
- `src/components/ProjectTree.tsx`: «Дом → Стены → Параметры / Окна / Двери / Каркас» + соединения, выбор окна и детали с подсветкой.
- `src/App.tsx`: интеграция дерева, корректировка выбора при Undo/импорте, версия импортируется непосредственно из `package.json`.
- `src/styles.css`, `tsconfig.app.json`: оформление и разрешение JSON-модуля.
- `scripts/browser-smoke.mjs`: браузерная проверка дерева, номера версии, выбора окон/досок, 3D, импорта/экспорта.
- Новые тесты `wall-module.test.ts` и `project-tree.test.ts`.

## Неизменяемые инварианты
- Исходный канонический `*.sigma4.json` не преобразуется в физически вложенные дублированные ветки.
- Владельца проёма и доски определяет `wallId`; `assembly` воспроизводится детерминированно.
- Физическая геометрия California corner X=5810..5955 мм сохраняется.
- `schemaVersion`, `rulesetVersion` и `generatorVersion` сохранены равными `1.0.0`. **Версия ПО 0.0.15 — отдельная сущность.**
- Функциональное ограничение на **две стены** остаётся до отдельного этапа S06.2; дерево способно отобразить девять ветвей, но физическую генерацию девяти стен этот этап не разрешает.
- Окна и двери на второй стене в интерфейсе пока отключены; следующий этап S06.3.
- `engineeringStatus='not_evaluated'`.

## Приёмочные проверки
`npm ci`, `npm run lint` (TypeScript), `npm test`, `npm run build`, Chromium с экспортом/импортом и скриншотами.

Результат CI фиксируется в Actions для SHA итогового коммита. Принятие пользователем — отдельное действие.

**Правила SIGMA4:** проверить ветку `sigma4` и исходный SHA; работать только в рамках ТЗ; JSON — единственный источник истины; сначала диагностика/тесты, затем правки; не ломать UTF-8 и прежние функции; представить lint/typecheck/tests/build и реальные скриншоты 3D; после успешной проверки — коммит и SHA; остановиться для приёмки.
