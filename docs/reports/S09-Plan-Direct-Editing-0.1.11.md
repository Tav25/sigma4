# SIGMA4 0.1.11 — прямое редактирование размеров на плане

Дата: 2026-11-05. Исходная ветка: \`sigma4\`. База: \`260e80941169b319db11f5dbbecf2563f78d2b22\` (0.1.1).
Следующее название версии определяется пользователем отдельно, не изменять без ТЗ.

## Рабочие возможности

- При выборе внутренней стены 2D-редактор вычисляет обе стороны размерной цепочки до ближайших *реально пересекающих сечение параллельных стен* и рисует две бирюзовые кликабельные размерные плашки.
- Клик по размеру и ввод в метрах (до 1 мм) с Enter перемещает выбранную ось стены перпендикулярно, сохраняя наружный периметр.
- В режиме «Выбрать» пользователь перетаскивает внутреннюю стену с шагом сетки. В ходе перетаскивания отображается предпросмотр; только итоговая проверенная геометрия попадает в ProjectStore одной атомарной командой.
- Концы остальных внутренних стен, прилегающих к перемещаемой оси, перемещаются вслед за ней; T-стыки не обрываются. Недопустимые изменения блокируются независимым валидатором. Пересечения «крест» перестраиваются как вычисляемые узлы.
- Отрисовка внутренних стен теперь использует реальную толщину \`thicknessMm\` вместо фиксированной линии.
- Наружные стены визуализируются полосами **внутрь** от неизменяемого наружного контура. Опциональное \`building.floorPlan.exteriorThicknessMm\` (50–500 мм) меняет эту толщину; отсутствие поля в старом JSON трактуется как 150 мм, без автоматической миграции.
- JSON остаётся единственным источником истины; Undo/Redo, JSON экспорт/импорт, существующие физические 3D-стены не заменены и не меняются по умолчанию.

## Контрольные примеры

1. Дом 10 × 8 м, осевая перегородка X=4000 мм и две зависимые горизонтальные стены: изменение левой размерной цепочки 4,00 → 4,50 м приводит к X=4500 мм, второй размер 5,50 м, оба T-соединения остаются привязанными.
2. Дом 6 × 4 м в реальном браузере: добавить две внутренние стены, выбрать вертикальную, изменить размер слева 3,00 → 3,50 м, мышью сдвинуть на 0,50 м (X=4000 мм), проверить сохранение зависимого конца, наружную толщину 200 мм, экспорт JSON и скриншот.
3. Недопустимое перемещение наружу и некорректная толщина должны быть отклонены без изменения JSON; Undo/Redo восстанавливает геометрию и связь.

## Качество и ограничения

Для проверки настроены \`npm ci\`, \`npm run lint\`, \`npm test\`, \`npm run build\`, Playwright Chromium в GitHub Actions. Статус каждого этапа определяется **фактическим** CI, а не текстом этого отчёта.

В данной версии **нет** автоматической генерации строительных досок и узлов из геометрии, расчёта несущей способности или вычисления помещений. Ширина стен — геометрическая визуализация 2D, а не полноценная конструктивная раскладка каркаса. Привязки и вычисления сейчас ортогональные; независимые диагональные контуры не поддерживаются.

**Правила SIGMA4:** перед работой проверить ветку и SHA; только назначенный этап; не переписывать историю Git; JSON единственный источник истины; валидация до записи; проверки typecheck/tests/build и браузерная регрессия; один содержательный коммит; остановка после отчёта для приёмки.
