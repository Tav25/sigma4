# SIGMA4 — S05.4: восстановлена недостающая стойка угла

Дата: 2026-11-02
Ветка: `sigma4`
Коммит кода: `dcf91d019819b90d671564187f12f3893f8c53d1`
Статус: READY_FOR_USER_TEST

## Найденная причина
По присланному снимку угла и экспортированному `project.sigma4 (3).json`: в каркасе были только стойка торца первой стены `stud-11` и начальная стойка второй стены `wall-002:stud-01`. В S05.3 третью стойку ошибочно полностью убрали вместе с неправильной тонкой рейкой 20 мм. Отсюда пустое место в угловом узле.

## Исправлено
- Добавлена **внутренняя полноразмерная стойка 45×145 мм** с ID `warm-corner-stud` и ролью `corner-backing`; данные формируются только генератором из параметров фасадной стены.
- В исходном контрольном каркасе стойка занимает X=5855..5900 мм, Y=45..2610 мм, Z=-72.5..72.5 мм. Наружная угловая стойка занимает X=5955..6000 мм, между ними остаётся полость 55 мм; боковая стойка касается их задних плоскостей, не перекрывая объёмы.
- Связь третьей стойки с боковой зафиксирована в `connectionIds`. Деталь меняет положение и длину вместе со стеной.
- Старые JSON с `warm-corner-cleat` 20 мм при пересчёте заменяются на новую полноценную стойку 45×145 мм.
- Обновлены тесты геометрии и импорта и добавлен тест переноса/изменения высоты стойки.

## Границы проверки
Код сохранён и перечитан из GitHub. Реальные `npm test` / `npm run build` **не запускались** в доступной среде, CI не подтверждён.
Конструктивная схема угла требует отдельной проверки креплений и нагрузок; `engineeringStatus=not_evaluated`.

## Пользовательская приёмка
1. Обновить `sigma4`, запустить, добавить вторую стену или импортировать присланный JSON.
2. На крупном плане изнутри должна появиться третья стойка стандартного сечения 45×145 мм, а не прежняя тонкая 20-мм рейка.
3. Проверить вид сверху: новая стойка стоит в углу, отдельно от наружной; между ними пространство под утеплитель.
4. Изменить длину фасада; стойка должна передвинуться вместе с правой стеной.
5. Проверить `npm test`, `npm run build` и отправить результат.
