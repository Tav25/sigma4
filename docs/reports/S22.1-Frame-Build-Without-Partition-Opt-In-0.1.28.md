# SIGMA4 0.1.28 — S22.1: исправление кнопки «Построить каркас»

**База:** `ed191ac4362e94f67545587621f5921764a94e17`, ветка `sigma4`.

## Воспроизведение
План 9000 × 6000 мм. Сквозная перегородка от (3000,0) до (3000,-6000), примыкающая ветка от (0,-3000) до (3000,-3000). После нажатия «Построить каркас» без промежуточного «Включить перегородки» команда отклонялась с `HAUN_MISSING_THROUGH_WALL`: проекция строила лишь наружные панели, тогда как конструктивный валидатор правильно требовал сквозную стену из двух 2D-отрезков.

## Исправление
- Команда `PLAN_FRAME_BUILD` автоматически включает внутренние стены, если на плане есть сегменты графа или legacy внутренние сегменты. Это одно атомарное изменение JSON с одной записью Undo.
- Построение без внутренних стен оставляет четыре наружные панели.
- Добавлено пояснение к кнопке и регрессионные тесты для двух порядков черчения, 6-метровой непрерывной обвязки, Т-приёмного узла, Undo/Redo и JSON.
- Chromium smoke повторяет план 9×6 и строит каркас без ручного переключателя.

**Границы:** никаких изменений конструктивной схемы Ларри Хона, расчёта несущей способности или старых тестовых проектов. После проверки остановиться на приёмку.

**Правила SIGMA4:** исходный SHA, ветка `sigma4`, JSON — канонический источник, тесты перед приёмкой, без force/reset, отчёт с реальными CI-результатами.
