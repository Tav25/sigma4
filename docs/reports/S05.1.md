## Что сделано

- В левой панели кнопка «+ Добавить вторую стену» и выбор «Стена 1 / Стена 2».
- Вторая стена длиной 3000 мм создаётся вдоль мирового +Z под прямым углом к первой (6000 мм вдоль +X), на уровне пола, с краем у торца первой стены. Расположение по умолчанию задаётся в JSON.
- Можно изменить длину, высоту и шаг стоек выбранной стены.
- Можно удалить вторую стену и сделать Undo/Redo через общий ProjectStore. Первый каркас и его окна сохраняются.
- Произведённые доски второй стены имеют уникальные ID с префиксом `wall-002:`, прежние ID первого каркаса сохранены.
- В документах координаты досок остаются локальными для стены (как ожидает действующий валидатор). При отрисовке применяется производный из `Wall.origin/orientation` перевод в мировые XYZ; нет второй независимо редактируемой модели.
- Камера автоматически подстраивает общий вид после добавления или удаления стены.

Изменены: `src/core/timber.ts`, `src/core/project-store.ts`, `src/core/ProjectStore.ts`, `src/scene/project-to-scene.ts`, `src/scene/SceneView.tsx`, `src/App.tsx`.
Добавлен `src/core/two-walls.test.ts` — **7 тестов**.

## Ограничения текущего небольшого шага

- Стены пока самостоятельные. При изменении длины первой стены вторая **не перескакивает автоматически** за её новым торцом. Подлинные узлы угла, крепления и пересечения стоек ещё не проектировались.
- Окна и двери для второй стены через UI пока отключены; доступны только на первой. Поддержка отдельных окон/дверей на второй стене с их корректным перетаскиванием — следующий шаг.
- Не вводить третью стену; команда `ADD_WALL` возвращает ошибку.
- Инженерный расчёт прочности не проводился (`engineeringStatus=not_evaluated`).
- Схема данных не менялась; старые одностенные проекты остаются совместимы.

## Проверки

Подтверждено чтением актуального кода из GitHub, что реализованы команды добавления/удаления, уникальные ID, проекция ориентации стены и 7 новых тестов.

**В этой среде не выполнены `npm test`, `npm run build` и визуальная проверка браузера.** Их результат ещё неизвестен.

## Как проверить

1. Запустить свежую версию и нажать «+ Добавить вторую стену».
2. Должны появиться две стены под 90°; камера должна показать обе.
3. Выбрать «Стена 2», изменить длину 3000→3500; первая не меняется.
4. Отменить и повторить изменение, удалить вторую стену, проверить Undo.
5. Проверить, что окна/двери первой стены и их маркеры работают.
6. Выполнить `npm test`, `npm run build`, передать результаты и скриншот двух стен.

Принимать S05.1 только после этих проверок.
