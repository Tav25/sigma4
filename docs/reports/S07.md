# SIGMA4 S07 — последовательная цепочка стен с замыканием

Дата: 2026-11-05, ветка sigma4, базовый SHA 14b5798fb635a7d89a13248b3f1d8659e7f0e9ac.

## Реализация (вариант 1)
- В разделе «Стены · цепочка» пользователь задаёт длину, поворот «Прямо / Направо 90° / Налево 90°» и нажимает «Продолжить стену». Новая стена строится строго от предыдущей; канонические координаты появляются в JSON через команду и независимый валидатор.
- Первое соединение +X → −Z сохраняет проверенную геометрию и стойки калифорнийского угла. Далее реальные стыковые углы получают раздельные угловые подрезки досок, чтобы их физические объёмы не пересекались.
- Поддержаны все четыре направления фасадного контура: +X, −Z, −X, +Z. Проёмы, маркеры и размеры проектируются на свои стены.
- Кнопка «Замкнуть контур» активна лишь если из свободного конца последней стены можно единственным прямым участком с правым углом добраться до физического наружного начала первой; длина вычисляется в миллиметрах и показывается до подтверждения.
- Одна атомарная команда добавляет замыкающую стену, создаёт торцевое соединение и сохраняет `building.closure`. Последний угол собирается без дубликата стоек; конструктивное замыкание контролируется валидатором.
- `REOPEN_CHAIN` атомарно удаляет замыкание и автоматически созданную последнюю стену, чтобы не оставлять доски в пересечении. Если в замыкающей стене уже есть проёмы, команда запрещена до их явного удаления. После этого можно менять и достраивать цепочку. Undo/Redo, JSON export/import и стандартные операции остаются доступными.
- При изменении длины стены, нарушающей замкнутый контур, команда возвращает понятную ошибку и не изменяет JSON.

## Точность и ограничения
- В параметрах авторская длина — вдоль наружной грани от узла цепочки до следующего; физические доски в стыковых углах подрезаются производно.
- Узел California рассчитан и протестирован только для первого +X→−Z, как прежде. Остальные правые/левые углы — геометрические деревянные стыки без проверки несущей способности и крепления.
- Одной кнопкой замыкается только ортогональная цепочка, если её последний свободный конец соосен с началом (произвольное самопересечение блокируется).
- Схема координат 1.1.0 сохранена; в JSON добавлены новые значения orientation, типы connections и необязательное поле closure. Программа 0.0.28.
- Вид сверху не используется для приёмки; Chromium снимки только в изометрии.

## Проверки
