# SIGMA4 S06.5.2 — exterior dimension arrows and sharp wall-aligned numerals

Version: **0.0.22**; branch: `sigma4`; base Git SHA: `99e6629fec2ca74a90a5a283d4f26fe879229ba4`.
User's requested fixes: arrows/extension lines not overlapping timber, sharp numbers (no texture blur), numerical labels always parallel to their corresponding individual walls.

## Root causes
- The dimension extension lines began at nominal wall `from/to` locations, i.e. inside timber; in oblique camera views the arrows/lines appeared over the construction.
- All previous text meshes shared the same fixed X orientation. Numbers on -Z walls did not rotate to follow their own dimension line.
- Digits were rasterized onto 512×128-pixel canvas textures. Low resolution, oblique minification and mipmapping caused blurring.

## Exact change
1. `src/scene/dimension-model.ts`: `dimensionLabelYaw` derives stable rotation from each dimension's own endpoints; `exteriorExtensionFoot` clips extension start points outside the **actual assembly world AABB** (100 mm outside). Annotations retain true source endpoints for engineering accuracy. Minimum plan offset is 650 mm, so arrows remain away from construction.
2. `src/scene/DimensionOverlay.ts`: replacing canvas textures with **resolution-independent vector line-stroke digits** (triangular mesh glyphs, 0–9), independent of zoom, device DPI and camera viewing angle; separate 3D quaternion per dimension places the text baseline along +X or −Z. Numerals only; remains on ground XZ; no CSS or floating labels. Extension strokes start outside timber, not at wall posts.
3. `src/scene/dimension-model.test.ts`: tests for X and −Z wall orientation, both exterior dimension axes, and outside-the-frame extension starts with preserved canonical model; negative/resilience cases.
4. `scripts/browser-smoke.mjs`: capture real WebGL isometric and top screenshots and check 6m × 3145mm exterior bounds for the L-corner layout, plus existing garage/window/door/JSON checks.
5. Version marker `package.json`/`package-lock.json`/UI updated to 0.0.22.

## Invariants
- No change to canonical JSON schema, wall positions, connection geometry, openings, generated boards, joint logic or validity rules.
- No hidden camera-coordinate substitutions: extension clipping is a rendering-only operation, never changes nominal measurement endpoints.
- Actual exterior dimensions remain based on placed timber Mesh AABB, including corner overlap.
- All digits remain parallel to the own wall's length dimension line in the horizontal XZ plane.
- Engineering status remains `not_evaluated`.
