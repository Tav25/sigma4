# SIGMA4 — S05.3: корректный тёплый угол и толщина досок

Дата: 2026-11-02
Ветка: `sigma4`
Коммит реализации: `246c77dcd85a6cc1b8b8ce23aedb3ff12f1a3cb1`
Статус: READY_FOR_USER_TEST

## Основание

Пользователь предоставил крупный план текущего угла, конструктивный пример тёплого канадского угла и экспорт `project.sigma4 (2).json`. В экспортированном документе у обоих `Wall.thicknessMm` было **45 мм**, хотя все обычные стойки имеют сечение **45×145 мм**, а реальная глубина стены — **145 мм**. Генератор добавлял непривычную сплошную узкую рейку `warm-corner-cleat` с сечением **20×145 мм**, которая неверно увеличивала количество досок в углу.

## Исправления

- Удалено создание `warm-corner-cleat`: угол формируется **двумя реальными стойками 45×145**, одной на торце фасада и одной в начале правой стены, с контактом по плоскости без пересечения объёмов. Открытая полость остаётся пригодной для утепления. Для обшивки предлагаются отдельные крепления, которые пока не моделируются как деревянные детали.
- Новый проект сохраняет `Wall.thicknessMm = Wall.sectionMm.height = 145`. Во время любого пересчёта и импорта старые документы с `thicknessMm=45` автоматически приводятся к физической толщине 145 мм. Сама геометрия обычных деталей 45×145 от этого не меняется.
- Проверка отступа проёмов около угла остаётся, но название и сообщение теперь относятся к угловым стойкам, а не удалённой рейке.
- Обновлены тесты S05.1 и S05.2, добавлено четыре регрессионных теста S05.3: корректная толщина, безопасная миграция старого JSON, отсутствие дополнительной стойки после импорта, перенос угла вместе с фасадом и Undo.

## Совместимость

- При импорте проекта из предыдущей версии все исходные окна, размеры, положения стен и история после импорта сохраняются. Генерируемые элементы пересчитываются: 20-мм рейка не возвращается.
- Старый экспорт пользователя также преобразован в отдельный исправленный JSON для визуальной проверки (вне GitHub); программа и без этого должна импортировать старый файл.
- Удалённая `corner-backing` по-прежнему разрешена в JSON-схеме только для распознавания старых файлов при импорте, но генератор более не выдаёт эту деталь.

## Что ещё не подтверждено

В текущей среде GitHub доступен, но исходный репозиторий нельзя клонировать и установить зависимости. **`npm test`, `npm run build` и визуальный запуск в браузере не выполнены**. Код опубликован, повторно прочитан из ветки, имеются 4 новых теста. Не считать этап принятым без пользователя.

## Как проверить

1. В новой версии добавить вторую стену, посмотреть крупным планом угол сверху: в углу нет отдельной тонкой (20мм) вертикальной рейки.
2. Выбрать торцевые стойки: обе должны иметь сечение **45×145 мм**.
3. Экспортировать JSON, проверить `building.walls[*].thicknessMm == 145`.
4. Импортировать предыдущий JSON пользователя с `thicknessMm=45` — он должен загрузиться и пересобраться без рейки.
5. Перемещение первой стены/изменение её длины, Undo/Redo, окна и двери продолжают работать.
6. Запустить `npm test` и `npm run build`, передать ошибки или подтвердить успех.

Примечание: визуальное сходство с учебным примером не является инженерной сертификацией крепежа, прочности и устойчивости; статус `engineeringStatus` остаётся `not_evaluated`.
