# SIGMA4 0.1.12 — свободные точки, ломаные и отрезки

Исходная ветка `sigma4`, стартовый SHA `8680d4b698af4849b6c61192e1fa7236c03a06b2`.
Рабочая версия: **0.1.12**. JSON продолжает хранить исходные координаты в целых миллиметрах.
Сохранён старый режим 3D, а его каркас **не** перестраивается автоматически из 2D.

## Что сделано
1. Свободная внутренняя точка: в пределах замкнутого наружного контура и на существующей стене.
2. «Ломаная»: любой старт, дальнейшие отрезки кликами под 90°, после каждого клика рисование продолжается; Enter/Esc завершает линию. «Поворот» фиксирует ось перпендикулярно предыдущему участку.
3. «Разделить»: точка на отрезке разрывает его на два самостоятельных участка (не короче 0,30 м).
4. «Удалить»: удаляет один указанный отрезок; другой участок, общие узлы и наружный контур сохраняются. Delete в режиме «Выбрать» и Undo/Redo доступны.
5. «Выбрать»: управление отрезками и узлами, перемещение мышью с привязкой; точный ввод координат узла и отрезка.
6. Пересечения внутренних ортогональных отрезков автоматически превращаются в общий графовый узел и разделяют пересекаемые участки. Валидация отвергает недопустимые наложения, незарегистрированные пересечения, диагонали, выход за наружный контур, короткие участки и повреждённые ссылки.
7. Для связанных коллинеарных внутренних участков перемещение двигает всю связанную цепочку и её общие Т-узлы, остальные концы поперечных стен автоматически меняют длину.
8. Канонический JSON `building.floorPlan.graph={nodes:[{id,xMm,zMm}],edges:[{id,a,b,thicknessMm}]}`.
   Поле `interiorWalls: []` сохраняется пустым для совместимости со схемой.
   Старые JSON v0.1.11 без `graph` читаются как прежде, а при первом редактировании новой геометрии переводятся в граф, без двух конкурирующих источников координат. Миграция не трогает 3D.
9. «Очистить внутренний план» сбрасывает узлы и отрезки, сохраняя наружные габариты.

## Испытания
- Новые unit/integration тесты `plan-graph.test.ts`, `plan-graph-store.test.ts`: 10 × 7 м, Г-образная кладовая, удаление правой половины стенки, свободные точки, повороты, split, ссылки узлов, миграция, undo/redo, ошибочные импорты и несущие 3D-элементы.
- Браузерный сценарий Playwright: новый план гаража, не привязанная к стенам точка, линия на всю ширину, пересечение с вертикальной стеной, удаление правого сегмента, точное изменение размера, повторное разделение и удаление, изменение свободной точки, экспорт/импорт JSON; скриншоты `23–26`.
- CI: `npm ci`, `npm run lint`, `npm test`, `npm run build`, `node scripts/browser-smoke.mjs`. Реальные итоги смотреть по URL GitHub Actions для коммита.

## Ограничения
- Только осевые стены и повороты 90°. 45° / произвольный угол позже.
- Свободные концы допустимы как архитектурный черновик. Они **не означают**, что конструкция готова к инженерной генерации каркаса.
- Визуализируемая толщина не является расчётом прочности.
- При переносе одиночного узла, нарушающем прямоугольность связанных участков, команда отклоняется; для смещения целой стенки используется «переместить отрезок».
- При миграции из legacy с пересечениями стен отдельные сегменты могут получить новые ID; координаты, толщина и топология сохраняются.

**Правила SIGMA4:** работать на `sigma4` от проверенного SHA, не выполнять force/reset и не переписывать историю; JSON единственный источник истины, валидация до записи, регрессии и Chromium, один осмысленный коммит, остановка для приёмки.
