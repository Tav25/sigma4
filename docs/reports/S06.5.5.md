# SIGMA4 0.0.25 — размеры непосредственно рядом со своими стенами

Дата: 2026-11-03. Ветка `sigma4`, исходный SHA `a51037768d8289284957c6af6ff4efa6d10dedaf`.

## Проблема
На Г-образной конструкции разметка первой стены с длиной 6000 мм ошибочно отодвигалась к глобальному `minZ`, хотя это конец второй, перпендикулярной стены. Размерная линия должна идти рядом с конкретной стеной, а не с противоположной границей всего здания.

## Исправление
- `dimension-model.ts`: для каждой стены вычисляется её собственный фактический AABB по физическим доскам с соответствующим `wallId`. Первая стена (+X) имеет линию на расстоянии **220 мм** от её наружной грани в +Z, вторая (-Z) — 220 мм от её наружной грани в +X. Обе остаются на плоскости XZ.
- Выносные линии начинаются на 45 мм за наружной гранью **этой же стены**; не пересекают внутреннюю площадь каркаса. Канонические исходные точки `from/to` остаются прежними.
- Отдельные наружные габариты здания, вычисляемые по физической сборке, располагаются на 460 мм от соответствующих внешних стен (вторая ближайшая размерная линия); не за противоположным углом строения.
- `DimensionOverlay.ts` использует собственные направления размерных линий для стрелок и надписей, надпись вынесена от линии на 160 мм вместо 240 мм. Все прежние требования (пол, vector font, читаемость, depthTest) сохранены.
- `dimension-model.test.ts`, `DimensionOverlay.test.ts`: регрессии для двух стен 6000×10000 мм; дополнительной отдельно размещённой стены; проверка реальных геометрических отступов от собственных досок и корректной выносной разметки.
- Chromium проверяет L-конструкцию и сохраняет контрольные кадры рядом с двумя стенами.
- Программа **0.0.25** (package.json, package-lock.json, маркер в UI). JSON 1.0.0 и физический генератор досок неизменны.

## Не сделано
- Произвольные повороты стен, новые типы углов/Т-стыков и инженерная прочность не относятся к этой правке.
- Общие габариты и длины отдельных стен остаются самостоятельными измерениями; могут совпадать численно.

## Проверки перед приёмкой
`npm ci`, `npm run lint`, `npm test`, `npm run build`; браузер Chromium/Playwright (вид сверху и изометрия, окна/двери/ворота, JSON).

**Правила SIGMA4:** проверить ветку `sigma4` и базовый SHA; работать только в рамках ТЗ; JSON — единственный источник истины; сначала тест/диагностика, затем правка; не ломать UTF-8 и прежние функции; показать результаты lint/typecheck/tests/build и фактическую 3D-проверку; после успешных проверок — коммит и SHA; остановиться для приёмки.
