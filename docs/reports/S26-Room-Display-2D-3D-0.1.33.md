# SIGMA4 0.1.33 — S26. Отображение замкнутых помещений в 2D и 3D

База: `de98d77ec5e1ef7d1e07772290cb00ce990049c4`. `sigma4`, без force/reset.

Изменения:
- 2D SVG: спокойная полупрозрачная заливка каждой вычисленной чистой области пола, подпись с номером и площадью в удобной точке внутри комнаты, выделение комнаты кликом. Предпросмотр перетаскивания перегородок пересчитывает области на лету.
- 3D Three.js: точно тот же набор прямоугольников как тонкий полупрозрачный визуальный пол (не конструктивная плита), подписи-спрайты, смотрящие на камеру. Все объекты производные, без рейкаста и записи в JSON. Геометрия и GPU-ресурсы освобождаются при изменении проекта / вкладки.
- Одно состояние переключателей «Площади»/«Заливка» в App; оно сохраняется при переходе между режимами. В 3D есть чистая суммарная площадь и количество комнат.
- Тесты world-метров и площадей; браузерная проверка на исходном 9×6 планe с T-веткой: 7,84 + 7,84 + 33,06 м², переключатели, 2D/3D снимки.
- Авторский JSON не меняется из-за выбора помещения или переключателей; вычисления всегда исходят из FloorPlan.

Ограничения: не нормативная жилая площадь; обычные плоскости пола не проектируют перекрытия; наименование комнат и экспликация — будущая версия. Сохранение названий комнат не добавлено без отдельного согласования.

**Правила SIGMA4:** проверить SHA и ветку sigma4; JSON — единственный источник истины; тест/диагностика до приёмки; без переписывания истории; отчёт lint/typecheck/tests/build и браузерных снимков; остановиться на визуальную приёмку.

## Важная особенность текущего проекта
При построении каркаса ProjectStore дописывает в JSON толщину наружного каркаса 145 мм, если до этого она не была задана. До сборки у графического черновика визуальная толщина по умолчанию 150 мм. Поэтому у примера 9×6 с Т-узлом чистая площадь меняется с 48,74 м² до 48,88 м². Тест проверяет совпадение итоговой площади в 2D и 3D **после** сборки и наличие в JSON именно 145 мм. Автоматическое согласование этих defaults на этапе черчения не входит в S26.
