# SIGMA4 — новая версия 0.1.0: редактор плана здания

Дата: 2026-11-05. Ветка `sigma4`, исходный HEAD `b118a465fbf34535b97fdd0e8efc151d0a0fee36` (откат S07 на 0.0.27).

## Решение интерфейса и концепции
1. При открытии пользователь попадает в **«План 2D»** — отдельный редактор, без перегрузки деталями стоек. Старый «Каркас 3D» сохранён в отдельной вкладке.
2. Наружный периметр начинается в мировом (0,0). Щелчки по сетке добавляют точки с ортогональной привязкой; числовой ввод «Длина участка (м)» + направление позволяет работать без мышиной погрешности. Масштаб, сетка 0,10/0,25/0,50/1,00 м, сдвиг Shift+drag, кнопка «Весь план».
3. Визуальная разметка: каждый отрезок имеет размер в метрах; дополнительная панель — габариты X/Z, суммарная длина, площадь после замыкания. Нумерация узлов и выделение первой точки. Замыкание нажатием на неё или кнопкой.
4. Исправление: редактирование координат узла, удаление последней точки, разомкнуть, очистить с подтверждением, Undo/Redo. Команды атомарные и проходят независимую геометрическую валидацию.
5. В каноническом JSON добавлено необязательное `building.floorPlan`: `exterior[]`, `closed`, `interiorWalls[]`. Координаты хранятся в миллиметрах. Новый план не переписывает физический 3D-каркас: до будущего этапа по нему не генерируются доски. Вкладка 3D прямо указывает на это.
6. Внутренние стены учтены **в архитектуре и схеме**, интерфейс их построения будет следующим отдельным этапом. План имеет один контур, максимум 32 вершины; пока только ортогональные сегменты 90°, длина не менее 0,30 м, точки в ±100 м, запрет самопересечений, обязательный незамкнутый/замкнутый статус.
7. Версия ПО и Git-маркер **0.1.0**, схема JSON по-прежнему **1.1.0**, добавление необязательного поля совместимо со старыми проектами. Существующие 3D-стены, углы, окна, двери, гаражные ворота и их тесты не затрагиваются.

## Пределы этого этапа
- Не выполняется сборка каркаса по чертежу или расчёт конструктивных углов, в том числе замыкающего угла. Нельзя утверждать готовность инженерного каркаса по одному плану.
- Внутренние перегородки пока не редактируются; заложен отдельный список с точками начала/конца и толщиной.
- Отсутствуют диагональные стены/дуги, наружные зазоры и распределение окон непосредственно из плана.

## Проверки
`npm ci`; `npm run lint`; `npm test`; `npm run build`, реальный Playwright Chromium для 2D и 3D, экспорт/импорт JSON, контрольные скриншоты пустого и замкнутого плана.

**Правила SIGMA4:** работать только в `sigma4` с зафиксированным SHA, без force; JSON — один источник истины; валидация перед записью; тесты перед принятием; показ результатов CI и скриншотов; один коммит и остановиться для приёмки.
