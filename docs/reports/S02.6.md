# SIGMA4 — S02.6: камера по центру при запуске

Дата: 2026-11-02
Ветка: `sigma4`
Коммит кода: `32756d9359f3a8459443c567b4aa5f6acf8d5d16`
Статус: READY_FOR_USER_TEST

## Проблема
После запуска разработческой версии пользователь должен был нажимать «Сбросить вид», чтобы увидеть каркас. `src/main.tsx` включает React.StrictMode; при повторной установке эффектов на новом объекте сцены оставался флаг уже выполненной настройки камеры.

## Исправления
- При новом создании сцены сбрасывается флаг первоначальной настройки камеры.
- Автонастройка и кнопка «Сбросить вид» используют один и тот же код размещения камеры.
- Настройка запускается только после появления деревянных деталей и ненулевого размера области просмотра.
- Если размер области появился позднее, `ResizeObserver` повторяет попытку.
- После запуска ручной поворот и приближение камеры сохраняются; настройка не повторяется при каждом изменении окна/двери.

Изменённый файл: `src/scene/SceneView.tsx`.

## Проверки
Изменение опубликовано в GitHub и проверено повторным чтением исходного файла. Проверена связь с `React.StrictMode`.

В этой среде **не запускались** `npm test`, `npm run lint` и `npm run build`: доступ к GitHub есть, но локального клона с установленными зависимостями нет.

## Проверка пользователя
1. Полностью обновить страницу — стена должна сразу быть видна целиком и по центру.
2. Повернуть и приблизить камеру: она не должна сама возвращаться в исходное положение.
3. Нажать «Сбросить вид» — прежняя работа кнопки должна сохраняться.
