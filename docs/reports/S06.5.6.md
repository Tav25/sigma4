# SIGMA4 0.0.26 — физический нижний левый угол первой стены = мировой ноль

Дата: 2026-11-05. Ветка: sigma4.
Основа: fc77cfd7f463113cbbe8643a8ea46033e0c96a5a.

## Обнаружено
Ранее origin={0,0,0} означал срединную плоскость первой стены по Z. Физическая доска толщиной 145 мм лежала в Z=-72.5…+72.5. Мировая нулевая точка на рисунке не совпадала с реальным нижним левым наружным углом.

## Реализовано
- Первая стена нового проекта получает **origin=(0,0,-72.5)**; толщина занимает Z=-145…0, а физический нижний левый наружный угол первой стены — ровно **(0,0,0)**. По +X длина остаётся 0…L, Y=0 — низ.
- Все физические доски, окно/двери/ворота, углы и швы продолжают строиться из одного JSON. Нет экранного смещения или искусственного сдвига камеры.
- `world-origin.ts` вычисляет реальный геометрический левый нижний наружный угол и переносит все стены **одним жёстким вектором**.
- Для старых JSON координаты при импорте не изменяются автоматически. Команда `ANCHOR_FIRST_WALL_AT_ZERO` с кнопкой в разделе проекта выполняет явную миграцию всей модели, включая независимо стоящие стены. Сохраняются Undo/Redo, экспорт и относительные координаты проёмов.
- Показаны физические координаты наружного угла, чтобы не путать их с осью стены.
- Тесты проверяют фактический 3D AABB (не только объявленные координаты), калифорнийский угол, импорт старого проекта, массовый перенос, Undo/Redo.
- Контрольная проверка реальной 3D-сцены — **только изометрия**, без вида сверху.

## Совместимость
Исходная схема и формат канонического JSON не меняются. Для старого файла исходное положение сохраняется до нажатия кнопки привязки; только тогда координаты стен изменяются и пересохраняются. Стандартная физическая геометрия и несущие расчёты не меняются.
