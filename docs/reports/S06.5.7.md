# SIGMA4 v0.0.27 — начало первой стены (0,0,0) в JSON и интерфейсе

Дата: 2026-11-05. Ветка sigma4. Исходный коммит: 8d85350b81167644a7f157492831836e836fb764.

## Требование
Нижний левый наружный угол первой стены, значения X/Y/Z в интерфейсе и поле wall.origin в JSON — все строго (0,0,0). Значение Z=-72.5 оставлять в JSON нельзя; смещение должно быть только производным внутренним параметром генератора.

## Реализация
- Схема 1.1.0: wall.origin хранит настоящий наружный начальный угол. Стена +X имеет физическую толщину в -Z, стена -Z — в -X. Половина глубины стойки вычисляется через wallMidplaneOrigin лишь для Three.js, 3D проёмов и валидации соединения.
- Новая стена: origin={x:0,y:0,z:0}. Правый калифорнийский угол и добавленные стены используют новые наружные координаты. Мировые Mesh остаются в прежних местах.
- Отметка глобального нуля теперь физически стоит на нижнем наружном углу первой стены, без искусственной подмены подписи координаты.
- Legacy v1.0.0: импорт переводит источники с центральной плоскости на наружную, сохраняя мировое положение досок и проёмов. Старые проекты не сдвигаются автоматически. Если физический угол старого проекта не в нуле, кнопка привязки переводит весь план в ноль с Undo/Redo.
- Схема, пример JSON, тесты и метка версии приложения синхронизированы; сохранён источник истины — JSON. Доски детерминированно пересчитываются.
- Включены проверки 3D координат, импорта и полного браузерного цикла. Контрольные скриншоты — только изометрия.
