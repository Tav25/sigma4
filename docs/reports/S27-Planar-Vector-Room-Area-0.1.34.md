# SIGMA4 0.1.34 — S27 3D-площади как размеры стен

Исходная ветка `sigma4` / SHA `59cad097798b7a5d59358052f40d1fb141638d39`.
Только графическое представление 3D-площадей.

- Удалены белые растровые карточки `THREE.Sprite`/`CanvasTexture` и `depthTest:false`.
- Подпись каждой комнаты теперь векторные glyph outlines `THREE.ShapeGeometry` через тот же Helvetiker `FontLoader`, что и размерные числа на стенах, размер базовых чисел 0.18 м, те же цвета CAD (обычный `0x274559`, выделенный `0x1562a8`).
- Единицы `m²`: векторное `m` и поднятый уменьшенный glyph `2`; кириллицу не подменяем отсутствующими glyph в font. Нет подложек или рамок.
- Группа числа, единицы и степени лежит горизонтально на XZ. `SceneView` использует **тот же** `orientDimensionNumbers` для разворота по камере только на 180 градусов — сохраняется параллельность плану и читаемость вида сверху. Материал depthTest=true/depthWrite=false, доски перед текстом перекрывают подписи.
- Данные room polygons/числовые площади, выбор помещения, показ/скрытие заливки, 2D и JSON не изменены.
- Новые unit-тесты проверяют отсутствие спрайтов, ShapeGeometry, общие правила символов и глубины, повороты камеры; Chromium проверяет атрибут режима и делает ISO/Top скриншоты.

Известное ограничение: `m²` показано латинским `m` из текущего технического шрифта. Нормативная проверка жилых площадей не входит в проект.

**Правила SIGMA4:** ветка `sigma4`, контроль base SHA, JSON — единственный источник истины, исходные проекты не мигрируются. Проверить TypeScript, unit, build, 3D Chromium и артефакты, остановиться на визуальную приёмку.
