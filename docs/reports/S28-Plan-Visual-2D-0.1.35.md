# SIGMA4 0.1.35 — 2D-01 / 2D-02: визуализация плана
Основание: `50a2adaaaebd90db3773ff1354c1ea1ff2675fb3`, ветка `sigma4`.

## Изменения
- Дефолтная визуальная наружная толщина согласована с базовой глубиной каркаса 145 мм (прежний незаданный параметр 150 мм приводил к скачку площади после сборки). Авторские явные значения сохранены.
- Мелкая сетка соответствует шагу привязки 100/250/500 мм, крупная — 1000 мм; на слишком малом масштабе сетка скрывается, а привязка остаётся активной.
- Масштабирование колёсиком фиксирует мировую точку под указателем; кнопки масштабируют вокруг центра.
- Внешние размерные линии направлены наружу по ориентации контура, включая вогнутые участки Г-образного плана. Добавлены выносные линии. Чрезмерно короткие подписи скрываются, не скрывая геометрию.
- Площади имеют три уровня детализации: полная подпись, компактная площадь и маркер с подсказкой; зонирование менее насыщенное.
- Вторичные узлы и вершины не загромождают замкнутый план и видны при наведении/выделении. Подчёркнуты границы стен и проёмы.
- Новые вычисления оформления вынесены в чистый `plan-visualization.ts`, не записывают геометрию в JSON.

## Проверки
Новые unit-тесты: внешние нормали при обоих направлениях обхода, вогнутые углы, сетка, закрепление масштаба, адаптивность площадей, равенство базовой глубины.
Полный CI репозитория выполняет typecheck, Vitest, build и Chromium smoke/snapshots при push. Проверять фактический статус отдельно.

## Ограничения
Пользовательская нестандартная толщина внешней стены по-прежнему не означает автоматически иной типоразмер реальных досок: существующий конструктор каркаса использует профиль 45×145 мм. Этот вопрос требует отдельного инженерного ТЗ; текущий этап его не меняет.

**Правила SIGMA4:** ветка sigma4 и базовый SHA сверяются перед изменениями; JSON — источник истины; тесты до приёмки; без force/reset; после проверок один коммит, остановка для визуальной приёмки.
