# SIGMA4 — S06.2: множественные стены, координаты и связи

Дата: 2026-11-02
Ветка: `sigma4`
База: `8074126eaab91aed37d77ba4b9fa19dff9cb6ffe`
Версия приложения: **0.0.16** (совпадает в package.json, package-lock.json и UI).

## Реализовано
1. `building.connections?: WallConnection[]` — необязательный массив, чтобы старые `*.sigma4.json` продолжали открываться. Допустимые конструктивные связи: `california-right` (первая пара X → -Z) и `end-to-end` (торцевое соединение в одном направлении). Отсутствующий массив в старом документе с двумя стенами означает прежний California corner; при добавлении третьей стены существующая связь материализуется.
2. `wall-topology.ts`: вычисление мировых торцов и консервативных пятен стен на плане, проверка ссылок, размеров, направлений, несовпадений координат, пересечений, циклов графа и повторного использования стыковочного конца. Присоединённые стены перестраивают положение из параметров родительской.
3. `ProjectStore`: добавление произвольного числа стен; независимые стены (без соединения) либо присоединённые (с типом). Удаление не разрешает потерять дочерние связи. Изменение длины и перемещение независимого родителя обновляют потомков. Поворот независимой стены вдоль +X/-Z возможен с обязательной проверкой; поворот присоединённой стены запрещён без алгоритма стыка.
4. `project-store.ts`: один генератор досок для каждой стены, независимый модуль для калифорнийского узла. JSON остаётся источником истины.
5. `App.tsx`: добавление присоединённой стены и свободной стены, удаление последней, отображение X/Y/Z, изменение X/Z независимой стены, выбор направления, счётчики стен и соединений. `project-tree.ts`: реальные связи всех стен.
6. Новые тесты `wall-topology.test.ts` включая девять стен, коллизии, недопустимые связи, наследование координат, Undo, JSON roundtrip. Браузерный сценарий включает создание девяти стен и скриншот сверху.

## Ограничения (важно)
- **Рабочие типы узлов:** торцевой стык одинаково направленных стен и уже проверенный калифорнийский угол первой пары.
- **Не реализованы:** T-образные узлы, произвольные углы поворота, замкнутые контуры, пересечения других типов. Вместо некорректных физических соединений валидатор отклоняет пересекающиеся стены.
- Схема `1.0.0` обратно совместима за счёт необязательного поля `building.connections`; скрытых координат вне JSON нет.
- Окна/двери и их маркеры на вторичной стене в интерфейсе остаются предметом **S06.3**.
- Инженерная прочность не рассчитана (`engineeringStatus: not_evaluated`).

## Верификация
`npm ci`, `npm run lint`, `npm test`, `npm run build`, headless Chromium (2 и 9 стен, экспорт/импорт, скриншоты), лог исполнения в GitHub Actions. Отчёт о прохождении — только после фактических результатов CI.

**Правила SIGMA4:** проверить ветку `sigma4` и исходный SHA; только утверждённое ТЗ; канонический JSON; сначала диагностика и негативные тесты, затем правки; без повреждения UTF-8 и старых функций; обязательные lint/typecheck/tests/build и 3D-проверка; после успешного тестирования зафиксировать SHA; остановиться для приёмки.
