# SIGMA4 0.1.20 — этап 1: верхние обвязки и примыкания стен

**Исходная контрольная точка:** ветка \`sigma4\`, SHA \`aed332bd69750351f7fd9597f4f952c8774f9ebb\`, версия 0.1.19.
**Область:** конструктивные верхние обвязки наружных стен и внутренних каркасных перегородок.

## Источник правила

Larry Haun, *The Very Efficient Carpenter*, "Double Top Plate", стр. 105–106; Larry Haun, *How to Build a House*, "Locking Walls Together". Нижняя (первая) верхняя обвязка идёт по стене. Второй слой должен перевязывать примыкания и пересечения. Для сквозной стены в верхнем слое оставляется канал в ширину примыкающей стены; верхняя доска примыкающей стены проходит через этот канал. Строительное правило сопряжений отличается от механического перекрытия габаритных прямоугольников.

## Реализация

- \`wall-module.ts\`: один общий генератор \`generateWallPanel\`, оба верхних слоя для всех связанных каркасных стен; толщина слоя 45 мм. Стойки перегородок теперь заканчиваются на нижней плоскости первой верхней обвязки.
- \`partition-door.ts\`: сохранены **оба** верхних слоя при наличии дверей; скорректированы высоты king-стоек и коротких стоек над дверной перемычкой, без изменения высоты двери.
- \`top-plate-laps.ts\`: новый **производный** генератор конструктивных верхних нахлёстов по топологии 2D-графа:
  - Наружный Т-узел: верхний слой сквозной наружной стены разделяется на две доски вокруг ширины перегородки. Верхняя доска перегородки продлевается через всю глубину наружной стены к её внешней грани.
  - Внутренний Т-узел: два коллинеарных сквозных отрезка образуют общий канал, а верхняя доска перпендикулярной перегородки проходит через обе половины стены.
  - Внутренний крест: верхние доски двух перпендикулярных ветвей сходятся в одной осевой плоскости; верхние доски двух сквозных ветвей подрезаны на половину толщины примыкающей стены каждая. **Две доски не накладываются друг на друга.**
  - Г-узел: верхний слой сквозного плеча освобождает место для нахлёста верхней обвязки примыкающей стены.
  - Несколько Т-узлов на одной стене: последовательная детерминированная разрезка второго слоя с устойчивыми ID; верхний слой наружных углов, рассчитанный \`connectPerimeterCorner\`, сохраняется за пределами мест примыкания.
  - Структура связывает физически соприкасающиеся детали через взаимные \`connectionIds\`.
- \`frame-validator.ts\`: только специально созданным вторым верхним доскам внутренних перегородок разрешён нужный локальный вылет (не более глубины максимальной сопряжённой стены). Другие доски не получают послабления.
- \`ProjectStore\`: JSON и исходные 2D-точки не мутируются ради верхних нахлёстов; сборка остаётся детерминированной.

## Ограничения

- Реализованы **одинаковые по высоте** ортогональные стены прямоугольного каркаса 2700 мм. Сопряжение разных высот, стен сложной произвольной формы, стальные накладки, разрывы для вентиляционных каналов, расчёт гвоздей и 4-футовый разбег заводских стыков обвязки в этот этап не включены.
- Связанные внутренние **ненесущие** перегородки получают два слоя ради сквозной перевязки; эта конфигурация ещё не является инженерно аттестованным профилем несущей стены.
- Правильное физическое соприкосновение досок проверяется геометрически. Несущая способность, количество крепежа и применение региональных нормативов остаются \`engineeringStatus: not_evaluated\`.

**Регламент SIGMA4:** работа строго в ветке \`sigma4\`; до изменения проверен SHA, без force/reset или переписывания истории. Один этап, один законченный набор регрессий, точный JSON как источник истины, после проверки — пользовательская приёмка.
