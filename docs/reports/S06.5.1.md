# SIGMA4 S06.5.1 — плоские размеры, только цифры

Дата: 2026-11-03. Ветка `sigma4`.
Основание: коммит `8aae86ef16a66a0d74ecdac67de93aeca4da6a7d`.
Версия ПО: **0.0.21**.

## Исправлено по замечанию пользователя
- **Все точки размерных линий** (измеряемые, выносные и стрелки) проецируются на мировую **горизонтальную плоскость XZ, Y=0**.
- 3D визуализация слегка приподнята над сеткой (25 мм) для предотвращения z-fighting, но сохраняет плоскостное положение (нет зависимой от высоты стены геометрии).
- Цифры — текстуры на **плоских треугольниках**, повернутых параллельно земле; они не используют billboard sprites и не следуют за камерой.
- Убраны подписи «Стена N», «Габарит X/Z», «мм», белые подписи-рамки, отдельная плавающая панель.
- Оставлены только цифровые значения размерных линий, их выносные линии и стрелки; глобальная отметка начала координат — отдельный неразмерный элемент.
- Числа в мм по соглашению проекта, без указания единиц на самих линиях.
- Canonical JSON, физические доски и координаты первой стены не меняются. Размеры производные, расчет остаётся корректным для California corner и нескольких стен.
- Исправлены и расширены тесты на Y=0 и числовые значения; браузерный smoke проверяет отсутствие HUD, переключатель, импорт 4м стены и изменение до 5м с контрольными снимками.

## Критерии принятия
`npm ci`, `npm run lint`, `npm test`, `npm run build`, Chromium 3D, screenshot сверху/изометрия/4м, проверка экспортируемого JSON. Не объявлять успешным до фактического прохождения GitHub Actions.

**Правила SIGMA4:** проверить ветку `sigma4` и базовый SHA; работать только в рамках ТЗ; JSON — единственный источник истины; сначала тест/диагностика, затем правка; не ломать UTF-8 и прежние функции; показать результаты lint/typecheck/tests/build и фактическую 3D-проверку; после успешных проверок — коммит и SHA; остановиться для приёмки.
