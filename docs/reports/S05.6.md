## Основание и конструкция

По деталям APA: *Insulated Three-Stud Corner (California Corner)*, DT-AF-2 и *Advanced Framing Construction Guide* M400B; дополнительная внутренняя стойка в утепляемом трёхстоечном углу ставится плашмя, освобождая доступ к утеплению. Этот вариант отличается от двухстоечного угла с клипсами.

Фасад (X): 6000 мм. Боковая стена идёт в сторону -Z. Сечение обычных стоек 45×145 мм.

## Изменено

- `src/core/project-store.ts`: стойка `warm-corner-stud` с сечением 45×145 повёрнута на **90° вокруг вертикальной продольной оси** (`orientation: { mode:'y', roll:90 }`). Её координаты вычисляются по сечению из JSON, а не константами.
- Для фасада 6000 мм физический след стойки по горизонтали X=5810..5955, Z=-72.5..-27.5 мм. Внешняя фасадная стойка X=5955..6000, Z=-72.5..72.5 мм. Стойка боковой стены X=5855..6000, Z=-117.5..-72.5 мм.
- Угловые стойки соприкасаются плоскостями, без пересечения объёмов; за плоской дополнительной стойкой остаётся **100 мм глубины полости под утепление**.
- `src/core/frame-validator.ts`: вертикальные доски, повёрнутые на 90°, проверяются по реальным габаритам, то есть их 145-мм размер теперь учитывается по X.
- Обновлены `warm-corner.test.ts` и `legacy-corner.test.ts`, добавлен `california-corner.test.ts` с четырьмя новыми проверками реального горизонтального сечения XZ, правильного разворота, отсутствия объёмного пересечения, импорта прежнего JSON и Undo при изменении длины.
- `src/App.tsx`: уточнено краткое описание типа угла.
- Исходный `project.sigma4 (4).json` отдельно преобразован в `SIGMA4_California_corner_corrected.json` для немедленного импорта, сохранив все стены и окна.

## Контроль

Повторно прочитаны опубликованные файлы и HEAD ветки GitHub. Вне Three.js независимо рассчитаны прямоугольники горизонтального сечения трёх угловых стоек; они соприкасаются, не пересекаются.

**Полный запуск `npm test`, `npm run build` и браузерная проверка ещё не выполнялись в этой среде.** Для последнего коммита нет опубликованного CI-статуса.

## Приёмка

1. Скачать актуальную ветку, запустить SIGMA4. Импортировать приложенный контрольный JSON либо свой старый JSON (после импорта генератор сам пересчитает угол).
2. Сверху: третья стойка лежит плашмя вдоль фасада, а не стоит как обычная; три стойки соприкасаются без наложений.
3. После изменения длины фасада угол сохраняет форму и положение, Undo восстанавливает начальное.
4. Запустить `npm test` и `npm run build` и сообщить результат.

Не трактовать геометрию как инженерную проверку креплений, несущей способности и строительных норм конкретного объекта: `engineeringStatus='not_evaluated'`. Полноценный интерактивный срез по Y (плоскость XZ) — отдельный UI-этап, здесь внедрены только геометрические тесты сечения.
