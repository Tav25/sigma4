# SIGMA4 0.1.32 — UX-01: защита проекта и согласованность режимов

База: ветка `sigma4`, SHA `205dbf7405db6d9d9f1d1370d92d509323fe287b`. Работа исключительно в новой ветке `ux-audit-0.1.32`.

## Реализовано

1. Локальная копия проекта автоматически сохраняется после успешной команды/Undo/Redo/импорта. При следующем открытии страницы проверяется и восстанавливается канонический JSON. Восстановление создаёт новое начальное состояние истории без возможности ошибочного Undo к демо-проекту.
2. Кнопка «Сохранить JSON» в верхней панели явно выгружает переносимый файл. Показан статус локального сохранения, включая ошибку недоступного хранилища.
3. Общая панель ошибок доступна как в 2D, так и в 3D; ошибки импорта не исчезают автоматически, их можно закрыть.
4. `SafeNumberInput` предотвращает повторную отправку значения при Enter + blur, связывает label/input для клавиатуры и сообщает об отклонении команды.
5. 2D-план не размонтируется при переключении вкладок: сохраняются масштаб, панорамирование, выделение и активный инструмент.
6. 3D-вид не размонтируется при переходе в горизонтальный разрез или в план, сохраняются положение камеры и графические ресурсы. При скрытом режиме рисование пропускается.
7. Видимость размеров больше не вызывает принудительное изменение камеры. В связанном каркасе курсор не обещает недоступное перетаскивание проёма.
8. Горизонтальный разрез использует общее выделение детали с деревом и 3D. При клике по древесине в 3D прежнее выделение проёма сбрасывается.
9. Раскрытие веток дерева больше не зависит исключительно от текущей стены: ранее вручную раскрытые ветки остаются открытыми.
10. Добавлен Playwright smoke `scripts/ux-smoke.mjs` (переключение 2D/3D, восстановление JSON, ошибки импорта, один Undo по Enter, общий выбор детали и сохранение Canvas). Workflow запущен и на `ux-audit-*`.

## Границы работ

Не затрагиваются алгоритмы каркаса, 3D-геометрия, инженерная валидация и формат JSON. Переработка единого инспектора для всех проёмов, компактных панелей 3D, пресетов камеры, адаптивности и полной библиотеки диагностики остаётся отдельным этапом после приёмки UX-01.

Локальное сохранение относится к **одному браузеру и профилю**: файл JSON рекомендуется выгружать отдельно. Работа в нескольких вкладках одновременно, квоты хранилища и удаление браузерных данных ещё не обеспечены отдельным интерфейсом управления резервными копиями.

## Проверка

Для этой ветки: `npm ci`, `npm run lint`, `npm test`, `npm run build`, `node scripts/browser-smoke.mjs`, `node scripts/ux-smoke.mjs`. GitHub Actions запускает их при push. Отдельно проверять успешный итог CI и браузерные снимки перед приёмкой.

**Правила SIGMA4:** от исходного SHA, только указанная новая ветка, JSON — единственный источник истины, без force/reset, один осмысленный коммит с результатами проверок и остановка на приёмку.
