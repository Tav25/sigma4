## Задача

По плану `02_ARCHITECTURE.md` проверить, что сцена Three.js строится из `ProjectDocument.assembly.elements`, без второго независимого списка досок. Проверить реальные мировые координаты X/Y/Z и физические размеры существующих деталей.

## Сделано

- `src/scene/project-to-scene.ts`: единый небольшой адаптер `ProjectDocument → элементы Three.js и проёмы`, который сохраняет размеры в миллиметрах и копирует координаты для изоляции данных.
- `src/App.tsx`: удалены две отдельные функции преобразования, вместо них используется новый адаптер. Интерфейс и логика перетаскивания не менялись.
- `src/scene/project-to-scene.test.ts`: 5 новых тестов:
  1. Все детали и проёмы сцены соответствуют JSON.
  2. Реальные границы нижней/верхних обвязок и крайней стойки для стены 6000×2700 мм.
  3. Дверь D01: разрыв нижней обвязки, перемычка и отсутствие обычных стоек внутри проёма.
  4. Изменение X двери перестраивает физические детали; Undo восстанавливает их.
  5. Изменение данных для отрисовки не меняет исходный JSON.

Тесты используют `THREE.Box3` для проверки мировых границ досок в метрах. Ожидания заданы независимыми числами, например нижняя обвязка X=0..6 м, Y=0..0.045 м, Z=-0.0725..0.0725 м.

## Важные замечания

- В исходной модели `Wall.thicknessMm` сейчас 45 мм, хотя физическая толщина каркаса по оси Z составляет 145 мм. Это наследованная несогласованность S01; не исправляли без согласованного правила совместимости старых JSON. Не считать данный параметр инженерно проверенным.
- Преобразование произвольного `Wall.origin/orientation` в мировые координаты нескольких стен — задача S05. На S03 проверяется действующая одна стена вдоль X.
- Проверка XYZ не является расчётом прочности; `engineeringStatus` остаётся `not_evaluated`.

## Проверка пользователя

1. Открыть программу, убедиться, что вся стена видна.
2. Переместить окно и дверь, проверить правильную перестройку досок.
3. Undo/Redo должны возвращать каждое перетаскивание одним действием.
4. На локальном компьютере выполнить `npm test` и `npm run build` и сообщить ошибки, если есть.
