# SIGMA4 v0.0.24 — исправление перекрытия размеров каркасом

Дата: 2026-11-03.
Ветка: `sigma4`; основа: `a092d93a4a77f449f76b8f0ea7034f8e8ea1df73`.

## Обнаруженная причина
Размерные линии, треугольные стрелки и плоские векторные цифры задавали `depthTest: false`. Даже расположенные на XZ элементы принудительно рендерились **поверх** стоек, окон и обвязки. `renderOrder` не заменяет проверку глубины.

## Исправление
- В `DimensionOverlay.ts` для линий `LineSegments`, стрелок `Mesh`, надписей `ShapeGeometry` и маркера глобального нуля включено `depthTest: true`. `depthWrite: false` у размерных объектов сохранено: они не маскируют друг друга и каркас в буфере глубины.
- Размерные и выносные линии остаются в горизонтальной плоскости XZ, Y ≈ 0.026 м над сеткой; их расположение выносится за границы фактической геометрии.
- Векторные цифры Helvetiker высотой 0.18 м, индивидуальное направление текста по стенам, маленькие планарные стрелки — без изменений.
- Новый регрессионный модульный тест проверяет глубинный буфер у всех объектов разметки и наличие глубины у центральной точки.
- Версия синхронизирована до **0.0.24** в UI и package*.json; канонический JSON и инженерная геометрия не меняются.
- Браузерный smoke: изометрия и вид сверху, снимки, экспорт JSON, работа ворот/окон/дверей.

## Приёмка
Только после успешных `npm run lint`, `npm test`, `npm run build` и Playwright Chromium 3D.

**Правила SIGMA4:** зафиксировать исходную ветку и SHA; только согласованный этап, без опережения; JSON — единственный источник истины, независимая валидация обязательна; не затрагивать прежние функции и историю Git; тестирование и реальная 3D-проверка; SHA коммита, затем остановка для приёмки.
